Little Sisters of St. Francis Website
Overview
This is the official website for The Little Sisters of St. Francis – North Eastern Region, Tanzania. The site is built using HTML, Bootstrap 5, and custom CSS/JavaScript to provide a responsive, accessible platform to showcase the congregation’s mission, ministries, and outreach.
Folder Structure

index.html: Homepage
pages/: Individual pages (about.html, ministries.html, etc.)
assets/css/: Custom styles (style.css)
assets/js/: Custom scripts (main.js)
assets/images/: Images for hero, ministries, and gallery
favicon.ico: Website favicon

Setup Instructions

Clone or download the project.
Open index.html in a browser to test locally.
Replace placeholder images in assets/images/ and text in HTML files with actual content.
Deploy to a hosting service (e.g., GitHub Pages, Netlify) for public access.

Dependencies

Bootstrap 5 (via CDN)
Custom CSS and JavaScript (minimal)
